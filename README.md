# ARECIBO — every crop circle is a message / 每個麥田圈都是一段訊息

A browser-only generator that presses any sentence into a decodable binary crop circle, a tribute to the 1974 Arecibo message (1,679 bits = 73 × 23).
純前端的麥田圈生成器：把一句話壓成可解碼的二進位麥田圈，致敬 1974 年阿雷西博訊息。

- `index.html` — site, generator and decoder / 網站、生成器、解碼器
- `js/cropcircle.js` — renderer (grid / ring / original 1974) / 繪圖程式
- `js/arecibo-bits.js` — the 1974 message bits / 1974 原始位元
- No cookies, no third-party trackers. / 不用 cookie、不用第三方追蹤。

No ARECIBO token exists. Anyone selling one "from us" is not us. / 目前沒有任何 ARECIBO 代幣。
